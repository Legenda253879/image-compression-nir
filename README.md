# Алгоритмы сжатия изображений

Программная часть научно-исследовательской работы по теме «Алгоритмы сжатия
изображений». Волгоградский государственный университет, кафедра информационных
систем и компьютерного моделирования, направление 09.03.01, группа ИВТб-241.

Репозиторий содержит собственную реализацию ядра кодера JPEG и программы
вычислительного эксперимента, результаты которого приведены в отчёте.

Версия, соответствующая отчёту, помечена тегом **`v1.0`**. Все числа в
таблицах и на рисунках отчёта получены этой версией кода на наборе
изображений из папки `images`.

Паролей, ключей доступа и персональных данных репозиторий не содержит.
Тестовые изображения сформированы программно скриптом `prepare.py`.

## Что здесь есть

| Файл | Назначение |
|---|---|
| `jpeg_core.py` | ядро кодера JPEG: переход в YCbCr, субдискретизация 4:2:0, ДКП блоками 8×8, квантование, зигзаг-обход, код Хаффмана и обратный ход |
| `prepare.py` | формирование тестового набора из четырёх изображений разных типов |
| `experiment.py` | 240 измерений: объём, PSNR, SSIM и время кодирования для пяти форматов |
| `report_numbers.py` | расчёт чисел для таблиц отчёта, включая сверку с библиотекой libjpeg |
| `graphs.py` | кривые зависимости качества от битовой скорости |
| `dct_demo.py` | иллюстрация работы ДКП и квантования на реальном блоке 8×8 |
| `figures.py` | изображения тестового набора и артефактов сжатия |
| `gant.py` | диаграмма Ганта календарного плана |
| `images/` | тестовый набор, зафиксированный для воспроизводимости результатов |
| `results.csv` | результаты измерений, на которых построены таблицы отчёта |

## Установка

Требуется Python 3.11 или новее.

```
pip install -r requirements.txt
```

## Запуск

Порядок важен: эксперимент читает изображения, а графики читают результаты
эксперимента.

```
python experiment.py       240 измерений, около минуты
python report_numbers.py   числа для таблиц отчёта
python graphs.py           кривые качества и диаграмма сжатия без потерь
python dct_demo.py         рисунок с ДКП и квантованием
python figures.py          тестовый набор и артефакты сжатия
python gant.py             диаграмма Ганта
```

Скрипт `prepare.py` заново создаёт тестовый набор. Повторно запускать его не
нужно: набор зафиксирован в папке `images`, и пересоздание изменит изображения
`text` и `graphics`, поскольку они формируются отрисовкой шрифта. Все числа в
отчёте получены на наборе из этого репозитория.

## Воспроизведение результатов

После `experiment.py` файл `results.csv` должен совпасть с тем, что лежит в
репозитории. Размеры файлов, PSNR и SSIM не зависят от машины. Время кодирования
отличается, поскольку зависит от производительности компьютера.

Скрипт `report_numbers.py` печатает готовые строки для таблиц отчёта и сверяет
собственную реализацию кодера с библиотекой libjpeg по объёму энтропийно
закодированного потока.

## Проверка корректности кодера

| Проверка | Результат |
|---|---|
| ДКП и обратное ДКП возвращают исходный блок | отклонение порядка 10⁻¹³ |
| Матрица преобразования ортогональна | отклонение порядка 10⁻¹⁶ |
| Таблица квантования при качестве 50 | совпадает со стандартной |
| Порядок зигзаг-обхода | соответствует ISO/IEC 10918-1 |
| Объём потока относительно libjpeg | расхождение не более 2 % |
| PSNR относительно libjpeg | расхождение не более 0,5 дБ |

Файловый контейнер со служебными заголовками не формируется: целью было
измерить объём энтропийно закодированного потока, а не получить совместимый
файл JPEG.

## Использованные библиотеки

Pillow, NumPy, SciPy, scikit-image, Matplotlib.
